## 核心思想
[5岁小朋友都能看懂的SVM算法](https://www.bilibili.com/video/BV1es4y1F72m/?spm_id_from=333.337.search-card.all.click&vd_source=e2e1a4085929d0da4797d0b5f27681e1)
想分类的每个物体都视为n维空间中的一个点，点的坐标即为特征。svm通过在空间中画出一个**超平面**将这些点分为两部分。超平面可能有很多，目睹是要找一条**最优超平面**，使得这条线离两边最近的样本点**越远**越好
- **支持向量**：那些离分界线最近的“钉子户”点。模型只由这些点决定，其他的点挪动位置不影响边界。

- **间隔**：支持向量到超平面的距离，要做的就是**最大化**间隔

## 公式推导
### 支持向量的位置
- **上边界**：$w^T x + b = 1$

- **下边界**：$w^T x + b = -1$
$w$ 和 $b$ 可以任意缩放而不改变超平面的位置。为了计算方便，人为设定支持向量落在 $\pm 1$ 这两条线上
### 上下边界的距离
根据平行直线的距离公式
$$d =  \frac{2}{\|w\|}$$
为了方便计算，计算$\frac{2}{\|w\|}$的最大值常计算$\frac{1}{2}\|w\|^2$ 的**最小值**
于是，SVM 的**核心优化目标**就变成了：

$$\min_{w,b} \frac{1}{2}\|w\|^2$$
### 软间隔
现实中的数据集往往不是完美线性可分的
所以允许点跑错位置
$C$越大表示，容忍程度越小
$$\min \frac{1}{2}\|w\|^2 + C \sum \text{Loss}$$

## 代码实现
### 正则化参数
为了代码实现的方便（尤其是使用梯度下降时），通常用以下这个式子实现，$\lambda$ 是正则化强度
$$\min \lambda \|w\|^2 + \frac{1}{n} \sum \text{Loss}$$
### 每个点到边界的距离
$$Condition = y_i(w^T x_i - b)$$
 当$y_i$（真实值）与预测值 $(w^T x_i + b)$ 同号（condition > 0）代表分类正确，但只有当乘积 $\ge 1$ 才说明这个点不仅分对了，而且分的力度也足够
### Loss损失函数
当$condition > 1$就要考虑Loss函数进行补救
$Loss = 1 - y_i(w^T x_i - b)$
- **对 $w$ 求导**：$\frac{\partial}{\partial w} [1 - y_i(w^T x_i - b)] = -y_i x_i$

- **对 $b$ 求导**：$\frac{\partial}{\partial b} [1 - y_i(w^T x_i - b)] = y_i$
